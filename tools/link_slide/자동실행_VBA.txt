========================================================================
 리모컨 다음 버튼으로 시상 PPT에 진입하기 (매크로)
========================================================================

PowerPoint 의 하이퍼링크는 마우스 클릭에만 반응합니다. 리모컨이나 키보드의
'다음' 버튼은 링크를 무시하고 슬라이드만 넘깁니다. 이걸 우회하는 기본 기능이
PowerPoint 에 없기 때문에, 다음 버튼으로 진입하려면 매크로가 필요합니다.

아래 매크로는 슬라이드에 '진입하는 순간' 발동합니다. 어떻게 넘어왔는지를
따지지 않으므로 리모컨·방향키·마우스 모두 동작합니다.

------------------------------------------------------------------------
 A. 자동 설치 (권장)
------------------------------------------------------------------------
 1. install_macro.vbs 와 시상링크.pptx 를 같은 폴더에 둡니다.
 2. PowerPoint > 파일 > 옵션 > 보안 센터 > 보안 센터 설정 > 매크로 설정 에서
    'VBA 프로젝트 개체 모델에 안전하게 액세스' 를 체크합니다. (한 번만)
 3. install_macro.vbs 를 더블클릭합니다. 시상링크.pptm 이 만들어집니다.
 4. 만들어진 .pptm 을 닫았다가 다시 열고, 보안 경고에서 '콘텐츠 사용' 을 누릅니다.
 5. 슬라이드쇼를 돌려 리모컨 다음 버튼으로 진입되는지 확인합니다.

 진입이 안 되면 Alt+F8 에서 자동진입_켜기 를 한 번 실행해 보세요.
 (Auto_Open 이 실행되지 않는 환경에 대한 대비책입니다)

------------------------------------------------------------------------
 B. 손으로 넣기 (자동 설치가 안 될 때)
------------------------------------------------------------------------
 1. 시상링크.pptx 를 엽니다.
 2. 파일 > 다른 이름으로 저장 > "PowerPoint 매크로 사용 프레젠테이션 (*.pptm)"
 3. Alt+F11 로 VBA 편집기를 엽니다.
 4. 삽입 > 클래스 모듈. F4 로 이름을 clsShowEvents 로 바꾸고 아래 코드를 붙여넣습니다.
 5. 삽입 > 모듈. 이름을 modAwardLink 로 바꾸고 아래 코드를 붙여넣습니다.
 6. 저장하고 닫았다가 다시 엽니다. 보안 경고에서 '콘텐츠 사용'.

------------------------------------------------------------------------
 [클래스 모듈]  clsShowEvents
------------------------------------------------------------------------
Public WithEvents App As Application

Private Sub App_SlideShowNextSlide(ByVal Wn As SlideShowWindow)
    On Error Resume Next

    ' 시상에서 돌아온 뒤 다시 들어가는 반복을 막는다
    If gFired Then Exit Sub

    Dim shp As Shape
    Set shp = Wn.View.Slide.Shapes("BtnAwardFull")
    If shp Is Nothing Then Exit Sub        ' 링크 슬라이드가 아니면 아무것도 안 함

    gFired = True
    ' 클릭한 것과 똑같이 링크를 실행한다 -> 시상이 끝나면 이 화면으로 자동 복귀
    shp.ActionSettings(ppMouseClick).Hyperlink.Follow
End Sub

Private Sub App_SlideShowEnd(ByVal Pres As Presentation)
    gFired = False                          ' 다음 상영을 위해 초기화
End Sub

------------------------------------------------------------------------
 [표준 모듈]  modAwardLink
------------------------------------------------------------------------
Public gFired As Boolean
Private mEvents As clsShowEvents

Sub Auto_Open()
    Set mEvents = New clsShowEvents
    Set mEvents.App = Application
    gFired = False
End Sub

' Auto_Open 이 돌지 않았을 때 수동으로 켜는 용도 (Alt+F8 에서 실행)
Sub 자동진입_켜기()
    Auto_Open
    MsgBox "자동 진입이 켜졌습니다.", vbInformation
End Sub

------------------------------------------------------------------------
 알아두실 점
------------------------------------------------------------------------
 · 브리지 슬라이드가 1번 슬라이드면 안 됩니다. 이 이벤트는 상영을 시작하는
   시점에는 발동하지 않습니다. 예배 PPT의 마지막이면 문제없습니다.
 · OneDrive 로 동기화되거나 인터넷에서 받은 파일은 '제한된 보기'로 열려
   매크로가 차단될 수 있습니다. 파일 우클릭 > 속성 > '차단 해제' 를 확인하세요.
 · 매크로가 막혀도 화면 아무 곳이나 마우스로 클릭하면 동일하게 진입합니다.
   슬라이드 전체가 링크라 실패해도 손으로 넘어갈 길이 남아 있습니다.
 · 예배 전 반드시 리허설하세요. 실패 지점이 여럿입니다.
