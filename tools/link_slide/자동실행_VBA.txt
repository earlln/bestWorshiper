========================================================================
 슬라이드가 뜨자마자 자동으로 시상 PPT를 여는 방법 (VBA / 선택 사항)
========================================================================

PowerPoint 에는 "슬라이드 진입 시 하이퍼링크 자동 실행" 기능이 없고,
하이퍼링크는 마우스 클릭에만 반응합니다. 매크로 없이 되는 가장 가까운 방식이
시상링크.pptx (화면 아무 곳이나 클릭) 이고, 리모컨만으로 진입하거나 클릭조차
없이 자동으로 하려면 아래 VBA 가 필요합니다.

[ 이 방법이 필요한 경우 ]
  리모컨이나 키보드의 '다음' 버튼만으로 시상 PPT에 진입하고 싶을 때입니다.
  이 이벤트는 슬라이드에 '진입하는 순간' 발동하므로, 어떻게 넘어왔는지와
  무관하게 자동으로 링크를 실행합니다. 마우스로 클릭해도 되는 상황이라면
  매크로 없이 쓰는 기본 방식으로 충분합니다.

[ 먼저 알아두실 점 ]
  · 매크로 파일(.pptm)은 열 때마다 "콘텐츠 사용" 보안 경고가 뜹니다.
  · OneDrive 로 동기화되거나 인터넷에서 받은 파일은 '제한된 보기'로 열려
    매크로가 아예 차단되는 경우가 많습니다. 이때는 파일 속성에서 '차단 해제'가
    필요합니다.
  · 실패 지점이 여럿이라 예배 전 리허설을 꼭 해보세요.

------------------------------------------------------------------------
 설치 순서
------------------------------------------------------------------------
 1. 시상링크.pptx 를 엽니다.
 2. 파일 > 다른 이름으로 저장 > 파일 형식을 "PowerPoint 매크로 사용 프레젠테이션
    (*.pptm)" 으로 바꿔 저장합니다.
 3. Alt+F11 로 VBA 편집기를 엽니다.
 4. 삽입 > 클래스 모듈. 속성 창(F4)에서 이름을 clsShowEvents 로 바꾸고,
    아래 [클래스 모듈] 코드를 붙여넣습니다.
 5. 삽입 > 모듈. 아래 [표준 모듈] 코드를 붙여넣습니다.
    ※ 브리지 슬라이드가 1번 슬라이드면 안 됩니다. 이 이벤트는 상영을 시작하는
      시점에는 발동하지 않습니다. 예배 PPT의 마지막이나 중간이면 문제없습니다.
 6. 저장하고 파일을 닫았다가 다시 엽니다. (Auto_Open 은 새로 열 때 작동합니다)
    보안 경고가 뜨면 "콘텐츠 사용"을 누릅니다.

------------------------------------------------------------------------
 [클래스 모듈]  이름: clsShowEvents
------------------------------------------------------------------------
Public WithEvents App As Application

Private Sub App_SlideShowNextSlide(ByVal Wn As SlideShowWindow)
    On Error Resume Next

    ' 시상에서 돌아온 뒤 다시 들어가는 무한 반복을 막는다
    If gFired Then Exit Sub

    Dim shp As Shape
    Set shp = Wn.View.Slide.Shapes("BtnAwardFull")
    If shp Is Nothing Then Exit Sub          ' 링크 슬라이드가 아니면 아무것도 안 함

    gFired = True
    ' 클릭한 것과 똑같이 링크를 실행한다 → 시상이 끝나면 이 화면으로 자동 복귀
    shp.ActionSettings(ppMouseClick).Hyperlink.Follow
End Sub

Private Sub App_SlideShowEnd(ByVal Pres As Presentation)
    gFired = False                            ' 다음 상영을 위해 초기화
End Sub

------------------------------------------------------------------------
 [표준 모듈]  이름은 아무거나 (기본 Module1)
------------------------------------------------------------------------
Public gFired As Boolean
Private mEvents As clsShowEvents

Sub Auto_Open()
    Set mEvents = New clsShowEvents
    Set mEvents.App = Application
    gFired = False
End Sub

------------------------------------------------------------------------
 참고
------------------------------------------------------------------------
 · 자동 실행을 잠시 끄고 싶으면 Alt+F11 에서 Auto_Open 안의 두 Set 줄을
   따옴표(')로 주석 처리하면 됩니다.
 · 시상에서 돌아온 뒤에는 클릭해도 다시 들어가지 않습니다(gFired 가 막아줌).
   다음 순서로는 → 방향키나 리모컨으로 넘어가세요.
