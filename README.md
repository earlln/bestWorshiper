# 🙌 bestWorshiper

영어예배 어린이 **Best Worshiper** 선정을 돕는 웹앱(PWA)입니다.
매주 후보를 등록하고, 포인트를 주고, 점수 상위 인원을 자동으로 선정해 히스토리에 남깁니다.

## 주요 기능

- **주간 선정** — 날짜 선택(소급 입력 가능) → 후보 등록 → +/− 포인트 → 상위 N명 자동 선정 → 저장
- **자동 감점** — 최근에 뽑힌 아이는 지난주 −N점, 그 전주 −(N−1)점 … 순으로 자동 감점되어 여러 아이에게 고르게 기회가 돌아갑니다. 적용 주수(기본 5주)는 설정에서 변경할 수 있습니다.
- **아이 명단 관리** — 추가/수정/삭제, 사진·동영상 첨부, 비활성 처리, 가나다순 / 우선순위순 정렬(▲▼로 순서 조정)
- **히스토리** — 주차별 선정 기록 조회·수정, `날짜, 이름1, 이름2 …` 형식의 텍스트로 복사·다운로드
- **포인트 내역** — 아이별 수동 점수와 자동 감점, 사유·날짜별 상세 내역
- **백업/복원** — 사진·동영상까지 포함한 JSON 내보내기·가져오기

## 사용 방법

### 폰에 앱으로 설치하기

1. 브라우저로 배포 주소를 엽니다.
2. **아이폰**: Safari → 공유 버튼 → *홈 화면에 추가*
   **안드로이드**: Chrome → 메뉴(⋮) → *홈 화면에 추가* / *앱 설치*
3. 홈 화면 아이콘으로 실행하면 주소창 없이 앱처럼 열립니다.

한 번 설치하면 오프라인에서도 실행됩니다.

### 로컬에서 실행하기

```bash
node serve.js 8090
```

또는 Windows에서 `start.bat` 실행. 파이썬만 있다면 `python serve.py 8090` 도 됩니다.

## 데이터 보관 방식

모든 데이터는 **사용하는 기기의 브라우저(IndexedDB)에만** 저장됩니다. 서버로 전송되지 않으며, 이 저장소에도 아이들 이름이나 선정 이력은 포함되어 있지 않습니다.

기기를 바꾸거나 여러 기기에서 함께 쓰려면 **⚙ 설정 → 내보내기/가져오기**로 백업 파일을 옮겨주세요. 브라우저 데이터를 지우면 앱 데이터도 사라지므로 정기적인 백업을 권장합니다.

## 기술 구성

단일 HTML 파일에 담긴 순수 JavaScript 앱입니다. 프레임워크·빌드 과정·외부 의존성이 없습니다.

| 파일 | 역할 |
|---|---|
| `bestWorshiper.html` | 앱 전체 (화면 · 스타일 · 로직) |
| `sw.js` | 서비스 워커 — 오프라인 캐싱 |
| `manifest.json` | PWA 매니페스트 — 홈 화면 설치 |
| `serve.js` / `serve.py` | 로컬 개발용 정적 서버 |

저장소: IndexedDB (사진·동영상은 Blob으로 저장)

## 버전

현재 **v1.0.0**. 설정 화면에서 현재 버전 확인과 업데이트를 할 수 있습니다.

앱을 수정해 배포할 때는 `bestWorshiper.html`의 `APP_VERSION` 과 `sw.js`의 `APP_CACHE_VERSION` 을 함께 올려주세요. 캐시가 갱신되어 사용자에게 새 버전이 전달됩니다.
